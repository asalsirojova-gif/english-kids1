# English Kids — Find the Arabic Letter! 🌈

A mobile-first Arabic alphabet and beginner Tajweed-quality recognition game for children.

## Files
- `index.html` — app structure
- `style.css` — colorful responsive design
- `script.js` — 40-question quiz + scoring
- `icon.svg` — app/favicon icon
- `manifest.json` — installable web-app metadata

## Run
Open `index.html` in a browser, or upload the folder to GitHub Pages / Netlify.

## Tajweed note
The Sifah data uses a standard Sifat al-Huruf table for the 28 Arabic letters. Qalqalah is shown as conditional (“when Saakin”), rather than as an always-present quality. Alif is treated separately because Madd Alif does not have a fixed Sifah of its own.

This is an educational recognition game, not a substitute for learning pronunciation from a qualified Tajweed teacher.
